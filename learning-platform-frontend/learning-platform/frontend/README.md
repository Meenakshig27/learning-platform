## Run locally
```bash
cd frontend
npm install
npm run dev
```

## Deploy to GitHub Pages
```bash
npm run deploy
```
Then in the GitHub repo: Settings > Pages > Source: `gh-pages` branch.

## Connect the backend
Create `frontend/.env` with `VITE_API_URL=https://your-backend-url/api`.
Without it, the app runs on mock data.
